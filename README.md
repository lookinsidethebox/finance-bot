# finance-bot

Личный Telegram-бот на Node.js и Telegraf. На обычное сообщение владельца отвечает `✅ Бот работает` и показывает кнопки «Добавить выписку» и «Внести наличные траты». Сообщения остальных пользователей и сообщения в группах игнорирует.

## Настройка

Требуется Node.js 20 или новее.

1. `npm ci`
2. Скопируйте `.env.example` в `.env`.
3. Укажите `BOT_TOKEN` от @BotFather и числовые Telegram ID владельцев через запятую в `OWNER_IDS` (например, `123456789,987654321`).
4. Запустите `npm start` и напишите боту в личном чате.

Проверка: `npm test`.

## Данные о тратах

Операции хранятся в `data/transactions.json`, выученные соответствия описаний и категорий — в `data/category-rules.json`, исключения для выписок — в `data/exclusion-rules.json`, добавленные вручную категории — в `data/custom-categories.json`. Настройки наличных хранятся в `data/settings.json`. Все JSON-файлы в `data/` исключены из Git. В операции сохраняются дата, сумма, валюта, описание, категория и `owner` — числовой Telegram ID человека, приславшего трату. Номер банковского счёта не сохраняется. Начальный список категорий задан в `src/constants/categories.js`.

Нажмите «Добавить выписку», выберите банк и отправьте файл. Для **Hipotekarna** поддерживается `.xls` с листом `Stanje`; для **Payoneer** — `.csv`. Выписки Hipotekarna всегда импортируются в EUR без дополнительного вопроса. Столбец `Valuta` содержит дату операции, а не валюту.

Импортируются строки с `Odliv > 0`, кроме описаний, внесённых в исключения; поступления из `Priliv` пропускаются. Для незнакомого описания `Svrha` бот предлагает категорию, новую категорию или кнопку «Не учитывать». Последний выбор запоминается для этого банка и повторяющиеся операции с таким описанием больше не попадают в транзакции. Кнопка «Новая категория» позволяет сразу ввести название текстом: разрешены только буквы, дефис и пробел, первая буква станет заглавной. Новая категория появится в следующих списках с иконкой 🏷️. Повторяющиеся описания классифицируются автоматически; для Spotify используется постоянное начало описания без меняющегося кода. Повторный импорт сопоставляет операции по владельцу, дате, сумме, валюте и описанию с учётом одинаковых повторов. Форматы других банков будут добавляться отдельными импортёрами.

Из Payoneer импортируются завершённые списания с `Source` равным `USD balance` или `EUR balance`. Валюта берётся из `Source`, а `Target` сохраняется как описание операции. Поступления и переводы между собственными балансами пропускаются. Для нового `Target` бот предлагает выбрать категорию или исключить операцию; правила категорий и исключений хранятся отдельно для каждого банка.

Кнопка «Внести наличные траты» просит сумму и категорию, затем сохраняет операцию с текущей датой и временем в UTC. Валюта наличных по умолчанию — EUR. Команда `/currency` позволяет выбрать EUR, USD, RUB, TRY или RSD, а также добавить свой трёхбуквенный код валюты; выбранная валюта используется для следующих наличных трат и сохраняется в `data/settings.json`.

## Railway

Для Railway используйте `npm start` как команду запуска, а `BOT_TOKEN` и `OWNER_IDS` задайте в переменных сервиса. Бот использует long polling и должен работать как постоянно запущенный процесс. Для сохранения всех JSON при перезапуске и деплое подключите том к `/app/data`.

Первого числа каждого месяца в 12:00 по `Europe/Podgorica` бот напоминает всем ID из `OWNER_IDS` внести банковскую выписку. Отметки об отправке хранятся в `data/monthly-reminders.json`, чтобы перезапуск бота не дублировал рассылку. Если бот запускается позже полудня первого числа, он отправляет ещё не доставленные напоминания в этот же день.
