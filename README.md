# finance-bot

Личный Telegram-бот на Node.js и Telegraf. На обычное сообщение владельца отвечает `✅ Бот работает` и показывает кнопку «Добавить выписку». Сообщения остальных пользователей и сообщения в группах игнорирует.

## Настройка

Требуется Node.js 20 или новее.

1. `npm ci`
2. Скопируйте `.env.example` в `.env`.
3. Укажите `BOT_TOKEN` от @BotFather и свой числовой Telegram ID в `OWNER_ID`.
4. Запустите `npm start` и напишите боту в личном чате.

Проверка: `npm test`.

## Данные о тратах

Операции хранятся локально в `data/transactions.json`, выученные соответствия описаний и категорий — в `data/category-rules.json`, добавленные вручную категории — в `data/custom-categories.json`. Все три файла исключены из Git. В операции сохраняются дата, сумма, валюта, описание и категория; номер счёта и ID не сохраняются. Начальный список категорий задан в `src/constants/categories.js`.

Нажмите «Добавить выписку», выберите банк и отправьте файл. Для **Hipotekarna** поддерживается `.xls` с листом `Stanje`; **Payoneer** пока в разработке. Выписки Hipotekarna всегда импортируются в EUR без дополнительного вопроса. Столбец `Valuta` содержит дату операции, а не валюту.

Импортируются все строки с `Odliv > 0`, включая комиссии и переводы; поступления из `Priliv` пропускаются. Для незнакомого описания `Svrha` бот спрашивает категорию кнопками с иконками и запоминает выбор. Кнопка «Новая категория» позволяет сразу ввести название текстом; новая категория появится в следующих списках с иконкой 🏷️. Повторяющиеся описания классифицируются автоматически; для Spotify используется постоянное начало описания без меняющегося кода. Повторный импорт сопоставляет операции по дате, сумме, валюте и описанию с учётом одинаковых повторов. Форматы других банков будут добавляться отдельными импортёрами.

## Railway

Для будущего размещения используйте `npm start` как команду запуска, а `BOT_TOKEN` и `OWNER_ID` задайте в переменных сервиса Railway. Бот использует long polling и должен работать как постоянно запущенный процесс. Хранилище и дополнительные сервисы пока не требуются.
